# Kendi ses efektlerin

Varsayılan efektler kodla üretilir (`scripts/lib/synth.mjs`, ücretsiz, her seferinde aynı ses).
Kendi efektlerini kullanmak istersen (satın aldığın paket, ElevenLabs, kendi kayıtların):

1. Dosyaları bu klasöre koy (`whoosh-fast.wav`, `tick.wav` …).
2. `library/audio/selection.default.json` → `sfx` içindeki yolları bu dosyalara çevir.

Ya da Claude'a "efektlerimi değiştir" de; `marka-kimligi` skill'i yardım eder.
Lisansını bilmediğin sesleri repoya koyma.
