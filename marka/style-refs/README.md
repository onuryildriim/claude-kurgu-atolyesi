# Stil referansları

Beğendiğin videolardan **ekran görüntüleri** buraya. Claude bunlara bakıp *dil bilgisini* çıkarır
(yerleşim, tempo, yazı hiyerarşisi). Rengi ve logoyu kopyalamaz; görünüm her zaman `marka/MARKA.md`'den gelir.

Dosya adı: `<harf><no>-<kısa-açıklama>.jpg` (ör. `a01-soguk-acilis.jpg`). Her karenin altına bir satır yaz:

| Dosya | Kaynak (kanal, video, dakika) | Neyi seviyorum |
|---|---|---|
| | | |

İpucu: Claude'a "bu karelerin ortak dilini çıkar, visual-language.md ve MARKA.md'ye işle" de.
Not: Başka kanalların kareleri telifli olabilir. Repo herkese açıksa bu klasörü `.gitignore`'a ekle.
